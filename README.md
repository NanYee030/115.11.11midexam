# 簡易書籍管理系統 (Simple Book Management System)

一個基於 Python 命令列介面 (CLI) 開發的簡易書籍管理系統。本專案透過讀取 JSON 檔案管理書籍資料，支援瀏覽、新增、關鍵字搜尋、變更借閱狀態、統計資料顯示與 JSON 檔案匯出等功能。

---

## 專案功能說明

1. **顯示全部書籍**：清單化顯示目前系統內的所有書籍，包含編號、書籍編號、書名、作者、價格（含千分位格式）及借閱狀態。
2. **新增書籍**：可新增書籍資料，具備書籍編號重複檢查、欄位非空驗證，以及價格必須為大於 0 之整數的型別驗證。
3. **查詢書籍**：支援依書名關鍵字進行搜尋，查詢時不區分英文字母大小寫。
4. **變更借閱狀態**：輸入完整的書籍編號，可切換該書籍之「可借閱」與「已借出」狀態。
5. **顯示最後 3 筆書籍與統計**：運用列表切片 (slicing) 技術顯示最新的 3 筆書籍資料，並計算與顯示書籍總數、可借閱數、已借出數、價格合計（含千分位）及平均價格（保留小數點後兩位）。
6. **匯出書籍資料**：將記憶體中最新的書籍資料匯出寫入至 `output.json`，並維持適當的 JSON 縮排與中文 UTF-8 編碼。
7. **離開系統**：顯示「系統已退出」並結束程式執行。

## 環境需求與執行方式

### 環境需求
* Python 3.7 或以上版本
* 無須安裝任何第三方套件 (僅使用 Python 標準函式庫 `json` 與 `sys`)

### 執行方式
1. 請確保專案目錄下包含 `books.json` 初始資料檔。
2. 開啟終端機 (Terminal / Command Prompt) 並進入專案目錄。
3. 執行以下命令啟動系統：

```bash
python app.py
```

---

## 資料匯出方式

在主選單中選擇選項 `6`，系統即會將目前執行中的最新書籍列表寫入專案目錄下的 `output.json` 檔案中。該檔案以 UTF-8 編碼儲存，且支援中文直接閱覽與格式排版。
